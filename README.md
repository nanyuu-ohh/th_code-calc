# 泰国建筑法规设计指标速查（Beta版）- 内部使用指南

这是一个轻量级网页工具，主要用于泰国项目在概念 / 方案设计阶段快速评估建筑及相关专业的强制性合规指标，帮助设计人员在前期快速识别高度、面积、停车、洁具、疏散等关键风险点。

## 🚀 如何使用

**在线访问：**

- 无需安装环境，直接通过浏览器访问网页即可使用
- 推荐使用 Chrome / Edge
- 👉 [点击这里访问速查器](链接地址)
- 支持电脑端与手机端适配

**输入参数：**

- **项目定位：** 选择所在地（曼谷 / 外府）及是否位于 IEAT 工业园
- **建筑功能：** 支持多选，例如工厂、仓库、办公、商业、酒店、宿舍等
- **核心数据：** 填入高度、面积、层数、地下室深度等，用于判断是否触发“高层”“超大型建筑”等强制条款
- **辅助数据：** 按功能补充人数、男女员工数、客房数或座位数，用于洁具、停车及疏散等指标估算

**查看报告：**

- 点击“生成规范核查报告”后，页面将自动输出建筑、结构、暖通、给排水、电气、电梯 / 消防等专业相关指标
- 各指标卡片会标注参考法规或条文编号，便于后续追溯原文

## 💡 核心功能与注意事项

### 自动判定建筑级别

输入高度、面积、层数等参数后，系统会自动判断是否可能触发 MR33、MR55 等核心法规中的高层建筑、超大型建筑或地下建筑相关要求。

### 内置 MR63 洁具估算

可根据建筑功能、面积、人数、客房数或座位数估算马桶、小便斗、洗手盆、淋浴等数量。页面内置 MR63 洁具标准表，方便人工核对。

### 厂房疏散深算

当建筑功能包含“工厂”时，可进入厂房疏散深算模块，进一步核查：

- 本层最大同时使用人数
- 疏散出口数量
- 疏散门净宽建议
- 楼梯净宽建议
- 平面布置与防火构造提醒

### 混合功能测算局限

对于商业 + 办公 + 酒店等混合功能建筑，部分指标仍基于总面积或整体人数进行估算。若需更精确结果，建议按功能区分别填写、单独查算。

### 原文追溯

各指标卡片会附带法规名称或条文编号。页面底部提供泰国暹罗建筑师协会（ASA）等原文检索入口，正式判断前应回查法规原文。

## ⚠️ 免责声明

- 本工具数据截至 2026-04，当前仅抽取部分常用核心条款
- 工具输出结果仅供设计前期概算、内部沟通和风险识别使用
- 结构、暖通、给排水、电气、消防、电梯等专业提示仅为跨专业底线提醒，不代表完整专项计算
- 停车、洁具、疏散等结果需结合项目实际功能分区、当地解释及 LDI / 当地顾问意见复核
- 施工图设计、报建及审批仍应以泰国现行法规原文、当地主管部门要求和合作院最终核审意见为准
